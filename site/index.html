      Escriba o pegue el número de pedido y pulse «Buscar». Verá su boleta con el estado actual.

      Archivo de pedidos

      La base de datos guarda cada pedido como una ficha, ordenada por su número en cajones. El agente la busca cajón por cajón.

      0 – 4
      5 – 9
      a – f

      Escriba un número de pedido y pulse «Buscar».

      Ver cómo es en la base de datos (para programadores) 
      SELECT * FROM orders WHERE id = …;

      Aquí el agente busca cajón por cajón para que se vea. PostgreSQL de verdad es más rápido: usa el índice orders_pkey (un árbol B), que lo lleva directo al lugar donde debería estar la fila, sin revisar los demás cajones ni toda la tabla.

      Cómo funciona

      Cada pedido pasa por seis piezas del sistema construido en Go. Cada una tiene un agente bot con su color.

      1. Usted
      2. API en Go
      3. PostgreSQL
      4. RabbitMQ
      5. Worker
      6. Email
      Cliente

      Arma y envía

      Envía el pedido con su RUT y una clave única, para poder reintentar sin crear duplicados.

      API en Go

      Revisa y responde

      Comprueba que el pedido tenga sentido y responde en milisegundos con un número de pedido.

      PostgreSQL

      Guarda

      Guarda el pedido en la base de datos para que no se pierda aunque el sistema se reinicie.

      RabbitMQ

      Avisa

      Recibe el aviso «se creó un pedido» y lo reparte a cada trabajador que lo necesita.

      Worker

      Prepara

      Trabaja en segundo plano y deja el pedido listo para despacho. Si algo falla, lo reintenta.

      Email

      Notifica

      Envía un correo de prueba. Si el proveedor falla, reintenta esperando cada vez un poco más.
